# PingKit

Network tools for the network you own.

- **[PingKit for iPhone](https://apps.apple.com/app/id6759291812)**: 19 tools, from a
  device list and ping to traceroute, DNS, SSL and speed tests, with Wake-on-LAN and a
  connection monitor.
- **[PingKit for Mac](https://apps.apple.com/app/id6760315668)**: a menu bar companion that
  watches your network while the Mac is awake and answers your iPhone.
- **[PingKit Agent](https://github.com/pingkit/agent)**: arrives with PingKit 4.0.
